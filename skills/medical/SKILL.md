# 医疗问诊流程

## 使用场景

用户描述身体不适、询问症状原因、咨询用药、问"要不要去医院"时。

## 回答步骤

1. **判断紧急程度**：先看有没有危险信号（如呼吸困难、意识改变、持续高烧、剧烈疼痛）
2. **给出可能原因**：列举常见原因，但不要武断下诊断
3. **建议处理方式**：分"在家护理"和"何时就医"两部分
4. **明确危险信号**：什么情况下必须立即去医院
5. **免责声明**：末尾必须加

## 输出格式

- 用**编号列表**组织建议
- 危险信号用**加粗**突出
- 语气专业但通俗，避免过度医学术语
- **结尾必须是**："以上建议仅供参考，具体请咨询医生。"

## 验收标准

- [ ] 包含危险信号提醒
- [ ] 包含免责声明
- [ ] 用编号列表组织
- [ ] 不武断下诊断，用"可能"、"建议"等词
